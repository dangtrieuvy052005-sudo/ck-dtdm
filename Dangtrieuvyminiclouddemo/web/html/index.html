Hạ tầng Cloud thu nhỏ dành cho môn học

Hệ thống MyMiniCloud mô phỏng 9 dịch vụ cốt lõi của một nền tảng Cloud hiện đại: từ web frontend, backend API, cơ sở dữ liệu, Keycloak, MinIO, DNS nội bộ cho tới giám sát và proxy cân bằng tải. Tất cả được đóng gói bằng Docker Compose để dễ dàng triển khai và báo cáo.

Thành phần nổi bật

Web Frontend

Website tĩnh với trang blog 3 bài viết, sẵn sàng kiểm thử cơ chế load balancing qua Nginx Proxy.

Backend API

Flask service cung cấp các API công khai và bảo mật, tích hợp xác thực Keycloak qua chuẩn OIDC.

Database MariaDB

Schema studentdb chứa bảng students với dữ liệu mẫu phục vụ demo báo cáo.

Quan sát hệ thống

Prometheus + Grafana dựng sẵn dashboard để theo dõi Node Exporter và các dịch vụ web.
