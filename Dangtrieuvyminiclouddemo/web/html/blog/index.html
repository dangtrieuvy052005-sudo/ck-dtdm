Nhật ký triển khai MiniCloud

1. Thiết kế kiến trúc & phân chia dịch vụ

Tôi bắt đầu bằng việc chuyển yêu cầu “9 server” trong đề bài thành kiến trúc cụ thể: hai web server để cân bằng tải, một backend Flask, cơ sở dữ liệu MariaDB, Keycloak, MinIO, Bind9, Prometheus, Grafana và Nginx proxy. Docker Compose là chìa khóa giúp toàn bộ thành phần giao tiếp chung trên mạng cloud-net.

  • Xác định cổng, volume và biến môi trường của từng container.
  • Đảm bảo các dịch vụ có thể mở rộng và được proxy điều phối.
  • Viết tài liệu để báo cáo nêu rõ chức năng của từng khối.

2. Xây dựng pipeline bảo mật với Keycloak

API bảo mật là phần khó nhất. Tôi cấu hình realm master, client myapp và dùng PyJWKClient để tự động lấy public key khi giải mã JWT. Nhờ vậy endpoint /secure trả về payload chi tiết của token mà không cần tái triển khai mỗi khi Keycloak xoay khóa.

  • Tích hợp biến môi trường OIDC_ISSUER và OIDC_AUDIENCE.
  • Xử lý ngoại lệ rõ ràng để hỗ trợ kiểm thử và viết báo cáo.
  • Đảm bảo thông điệp lỗi tiếng Việt, sát với yêu cầu môn học.

3. Giám sát và trực quan hóa

Để đạt điểm tối đa, hệ thống phải có giám sát. Tôi thêm job cho cả Node Exporter lẫn cặp web server trong Prometheus. Grafana lấy dữ liệu từ Prometheus và hiển thị dashboard gồm biểu đồ CPU, lưu lượng truy cập và số request HTTP đến backend.

  • Cấu hình prometheus.yml theo đúng tên service.
  • Lên kế hoạch dashboard với ba biểu đồ tối thiểu.
  • Chuẩn bị hình ảnh minh họa để đưa vào báo cáo cuối kỳ.
